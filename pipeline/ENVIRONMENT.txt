Notes
-----
- CPU only. No CUDA, no GPU CatBoost (its GPU backend silently early-stops on Logloss).
- LightGBM is bit-identical across n_jobs. XGBoost `hist` and CatBoost are thread-count-sensitive;
  the shipped v4 members used n_jobs=8 / thread_count=8. The Honors notebook uses 2 threads
  for Colab, so it reproduces the recipe and CV within +/-0.004, not the CSV byte-for-byte.
- requirements.txt in the repo root uses compatible ranges rather than exact pins.
